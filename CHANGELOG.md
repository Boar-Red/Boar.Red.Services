# 更新日志 / Changelog — Boar.Red.Services

## 10.0.0 — 首个开源版本 / First Open-Source Release

Boar.Red 微服务框架以 MIT 协议开源。本仓库为聚合解决方案（元仓库），不含代码，仅含引用全部项目的解决方案文件与共享文档。

The Boar.Red microservice framework is open-sourced under the MIT license. This repository is an aggregate solution (meta-repo) containing no code — only the solution file referencing all projects, plus shared documents.
