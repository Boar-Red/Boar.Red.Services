## TypeScript项目开发规则
适用的开发语言：TypeScript
代码文件扩展名：.ts

### 代码文件要求
- 所有类、枚举、接口，都要独立文件保存，不允许多个定义在同一个文件中。

### 代码编写要求
1. 每行代码不要超过240个英文字符。
2. 函数参数定义时，优先在一行内定义，超出240个英文字符时，按参数定义为单元进行换行。

### 代码结构要求
- 类（Class）定义时，要遵循以下代码块顺序：
1. 静态常量
2. 静态变量
3. 自有属性
	1. 私有属性
	2. 公开属性
4. 类方法
5. 自身实现
	1. 私有方法
	2. 公开方法
6. 事件节点，注意事件方法的定义要以did，will开头，明确事件发生的时机
7. 重载
8. 接口实现
9. 所有代码块都要使用如下格式进行包裹，方便阅读代码时定位跳转：
```
////////////////////////////////////////////////  
// @当前代码块名称
////////////////////////////////////////////////

// #region 当前代码块名称

当前代码块代码

// #endregion 
```

### 模型定义要求
- 所有模型类的属性，除非明确指定，否则都应使用可选属性语法，定义为可为 `undefined` 的类型，如：`name?: string`。
- 模型属性不应默认定义为可为 `null` 的类型（如：`name: string | null`），也不应默认赋值为 `null`。只有业务或接口明确需要区分 `null` 与 `undefined` 时，才允许使用 `null` 类型。
